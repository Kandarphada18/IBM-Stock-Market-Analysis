# IBM Stock Market Analysis Dashboard

## Project Overview

This project analyzes IBM stock market data using Python and Power BI. Real-time stock data was collected from the Alpha Vantage API using the requests library. The dataset was cleaned and processed using Pandas, followed by dashboard visualization in Power BI.

## Technologies Used

* Python
* Pandas
* Requests Library
* Alpha Vantage API
* Power BI

## Features

* Real-time stock data extraction using API
* Data cleaning and numeric conversion
* Moving Average Analysis (MA5 & MA10)
* Daily Price Change Calculation
* Trading Volume Analysis
* Interactive Power BI Dashboard

## Dashboard Visualizations

* KPI Cards
* Line Charts
* Clustered Column Charts
* Volatility Analysis
* Volume Trend Analysis

## Project Workflow

API Data Collection → Data Cleaning → Feature Engineering → Dashboard Visualization
