# IBM Stock Market Analysis Dashboard

## Project Overview
This project analyzes IBM stock market data using Python and Power BI. Real-time stock data is fetched using the Alpha Vantage API and processed using Pandas for data cleaning and transformation.

The dashboard provides insights into:
- Latest stock price
- Highest and lowest prices
- Trading volume
- Daily stock price trends
- Moving averages (MA 5 & MA 10)
- Daily stock volatility

## Technologies Used
- Python
- Pandas
- Requests API
- Power BI
- Task Scheduler Automation

## Features
- Automated stock data updates
- API-based real-time stock data collection
- Interactive Power BI dashboard
- Moving average analysis
- Daily volume analysis
- Automated CSV data pipeline

## Project Workflow
1. Fetch stock data from Alpha Vantage API
2. Clean and process data using Pandas
3. Store updated dataset in CSV format
4. Automate updates using Windows Task Scheduler
5. Visualize insights using Power BI dashboard
